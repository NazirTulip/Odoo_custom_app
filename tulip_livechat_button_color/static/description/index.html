WHY THIS MODULE

Why Livechat Button Hover Color?

Odoo lets you set the Live Chat channel colour, but the hover states inside the chat window are not part of that setting. Buttons keep their default highlight, which rarely matches the rest of the widget. Fixing it normally means writing SCSS against Odoo's Live Chat asset bundle and knowing which bundle to target. This module is that work, already done.

CAPABILITIES

What it does

🎨

Consistent hover colour

Every button and link styled as a button inside the chat window uses the same hover background, border and text colour.
💬

Launcher bubble included

The floating Live Chat button gets the same treatment, with Odoo's default brightness filter removed so the colour stays true.
⚡

Scoped to the embed

The stylesheet is registered on the Live Chat embed bundle only. Backend and website buttons are untouched.
🛠

Nothing to configure

No settings page, no menu items, no records created. Install it and the styling is live.
GETTING STARTED

How it works

1

Install the module

Apps • search for Livechat Button Hover Color • Install. It depends on Live Chat only.
2

Open your site

The Live Chat embed picks up the stylesheet on its next load. A hard refresh clears any cached assets.
3

Hover a button

Buttons in the chat window and the launcher bubble now highlight in the module colour instead of the Odoo default.

What this module does not do

The colour is fixed in the stylesheet. There is no settings field. Changing it means editing static/src/scss/livechat_button_hover.scss and upgrading the module.

It styles hover states only. Resting colours still come from the Live Chat channel settings in Odoo.

It adds no fields, models or reports. If you need a configurable palette or per-channel colours, this is not that module.

UNDER THE HOOD

Technical detail

COMPATIBILITY

Odoo 17, 18 and 19, Community and Enterprise. Depends on im_livechat only.

No models, no access rules, no controllers. Nothing is stored and no request data is read.

One SCSS file on the im_livechat.assets_embed_core bundle, targeting .o-mail-ChatWindow and .o-livechat-LivechatButton.
